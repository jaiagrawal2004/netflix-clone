# Netflix Clone

A responsive Netflix Clone website built using HTML, CSS, and JavaScript.

## Features

- Responsive UI
- Movie Cards
- Netflix-inspired Design
- Hover Effects
- Multiple Sections
- Attractive Layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```
netflix-clone/
│
├── images/
├── css/
├── js/
├── index.html
└── README.md
```

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
